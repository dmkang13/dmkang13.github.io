# Classical Music Talk — Slide Content

This file controls the visible text in `classical-music.html`.

- Keep each `## slide-N` heading and each `### field-name` unchanged.
- Edit the text below a field heading.
- A new line inside `title`, `note`, or `reveal` creates a deliberate line break.
- Use `*italics*` or `**bold**` where useful.
- For `tracks`, use one line per piece:
  `Composer | Work | Display time | YouTube URL | Start seconds | End seconds`.
- For a single video, use `YouTube URL | Start seconds | End seconds` under
  `video`, `left-video`, or `right-video`.
- `speaker-notes` are presenter preparation only and are not shown in the HTML
  deck. They can use multiple lines, `*italics*`, and `**bold**`. They are not
  private if this Markdown file is included in a public deployment.
- For other lists, use one line per item. Keep the `|` separators where shown.

03 | Baroque | 1600–1750
04 | Classical | 1750–1820
05 | Romantic | 1820–1900
06 | Modern | 1880–1950

### speaker-notes
Clarify that “classical music” is the broad tradition; the Classical era is only one chapter.
Move quickly across the timeline so the audience feels the scale of the journey.
Invite them to listen for changing ideas about voice, motion, emotion, and color.

### speaker-notes

### speaker-notes
Describe the Renaissance ideal as balance, blend, and interwoven human voices.
Tallis writes forty independent parts without letting the whole collapse into noise.
Listen for sound passing between groups, almost like light moving through a building.

### speaker-notes

Motor rhythm supplies the forward pulse; ornament and harmonic tension create motion above it.

### era-notes

### speaker-notes
Stress that Modern is not one sound; it is a period of experiments and competing answers.
Some composers blur harmony, some sharpen rhythm, and others bring jazz or folk language into the concert hall.
Invite the audience to notice color and texture before deciding whether a piece feels “beautiful.”
